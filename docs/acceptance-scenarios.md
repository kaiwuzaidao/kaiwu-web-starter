# 采购申请验收

运行 `pnpm test:scenarios`。测试自行启动本地服务并使用合成数据。

| 场景 | 操作与预期 | 规则 |
| --- | --- | --- |
| S01 | 申请人新增、编辑、提交，重新读取单据为待审批。 | PR-01 PR-02 PR-05 |
| S02 | 已提交单据的编辑与删除均返回 409。 | PR-01 PR-05 |
| S03 | 经理批准阈值以内及等于阈值的申请，拒绝越级批准，仍能驳回大额单；重复审批返回 409。 | PR-03 PR-05 |
| S04 | 员工 B 无法读写 A 的草稿；普通申请人直接审批返回 403。 | PR-02 PR-04 PR-06 |
| S05 | 编辑和删除后详情与列表一致；状态筛选和翻页的总数按可见数据计算。 | PR-01 PR-04 |
| S06 | 经理在审批台完成大额单的第一级后仍为待审批，总经理完成第二级后变为已批准。 | PR-03 PR-05 PR-06 |

后端接手时用独立测试项目账号和隔离数据重跑这些行为，在服务端覆盖同一组拒绝用例。
