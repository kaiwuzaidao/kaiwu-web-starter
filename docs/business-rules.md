# 采购申请规则

| 编号 | 规则 |
| --- | --- |
| PR-01 | 标题必填，金额是正数的人民币元字符串，最多两位小数。只能编辑、删除自己的草稿。非草稿返回 409。 |
| PR-02 | 申请人提交自己的草稿。无提交权限返回 403。 |
| PR-03 | 审批金额严格超过流程清单阈值时，业务页面直接批准需要大额权限，演示身份均不持有。经理仍可驳回。在演示审批台，经理同意后进入升级节点，最后一级同意才将业务单据标记为已批准。 |
| PR-04 | 普通员工只看本人的申请。对不可见单据读取、修改、删除和提交统一返回 404。 |
| PR-05 | 草稿提交后进入待审批，待审批仅可批准或驳回一次。重复操作返回 409。 |
| PR-06 | 审批人必须拥有对应权限，且不能审批自己的申请。 |
